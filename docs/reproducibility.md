# Reproducibility

This project is organized so the same scripts can run from a small smoke test to the full WRDS-backed research package. The public repo includes the main scripts, configs, manifests, curated tables, and figure outputs. Licensed raw data must be regenerated by an authorized WRDS user.

## Local Verification

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
python -m pytest -q
python scripts/public_safety_scan.py --allow-any-root
```

On Windows PowerShell, use:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\public_safety_scan.py
```

## Output Contract

- `data/`: licensed raw, interim, processed, external, and cached data. Ignored by Git.
- `logs/`: runtime logs. Ignored by Git.
- `outputs/`: generated private run outputs, reports, and model binaries. Ignored by Git.
- `manifests/`: compact validation metadata. Included when it is small and non-sensitive.
- `docs/assets/figures/`: curated publishable figures.
- `docs/assets/tables/`: curated publishable CSV result tables.
- `docs/assets/reports/`: curated static HTML/PDF reports.

## Validation Gates

1. Preflight verifies project root, Python, GPU visibility, and credential mechanics without printing secrets.
2. WRDS smoke pulls a tiny month-end sample before full extraction.
3. Manifests track row counts, dates, validation statuses, and artifact paths.
4. Unit tests check timing, linkage, surfaces, costs, inference, visuals, and leakage-sensitive transformations.
5. `scripts/public_safety_scan.py` checks the public tree for credentials before publishing.
