# Curated Assets

This folder contains the publishable handoff artifacts from the final research run.

- `figures/`: headline visual abstract, numbered paper figures, dashboards, model diagnostics, and interpretation plots.
- `tables/`: CSV result tables for surfaces, backtests, inference, SDF models, mechanisms, external controls, and artifact QA.
- `reports/`: static HTML and PDF reports that can be opened directly from GitHub or downloaded.

The licensed raw WRDS pulls, processed Parquet panels, logs, and model binaries remain in ignored runtime folders and are not part of this artifact set.
